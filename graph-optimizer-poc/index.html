Learned search architecture

Exact reward plus learned future value

Actor proposals

A bounded pool of 64 legal actions is scored by the actor. Twenty-four are sampled from that distribution, then eight independent uniform actions are added.

Exact immediate reward

The optimizer temporarily evaluates each candidate's true objective change. The network is not asked to relearn arithmetic already supplied by the model.

Learned critic

The critic predicts discounted continuation return after each candidate. Candidate score is exact immediate reward plus discounted learned continuation value.

Actor–critic training

The critic learns from realized episode returns. The actor learns to place probability on candidates favored by exact reward plus critic value. The learned path does not use SA acceptance.
