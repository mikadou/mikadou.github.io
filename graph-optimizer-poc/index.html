A recurrent graph policy repeatedly chooses a variable and value for a shuffled strict chain xₐ > xᵦ > …. It receives no target assignments or depth labels: training uses only changes in violation energy, a step cost, a success bonus, and a terminal failure penalty.

What is implemented

Model and training

Graph state

Only variable nodes are represented. Directed edges encode greater than. Node IDs and tensor order are randomized between episodes.

Persistent memory

Every node owns a 32-dimensional hidden vector. Two directional message-passing rounds update it before each action. Hidden state persists inside an episode and resets to zero for a new instance.

Action

The policy scores every (node, value) pair. Training samples actions; evaluation takes the highest-scoring action. Exact no-op assignments are the only masked actions.

Reward-only learning

REINFORCE uses discounted returns and an entropy bonus. Reward comes from reducing violation energy, minus a small action cost, plus a feasibility bonus and a terminal penalty for remaining violations. No constructive solution or target value is supplied.
