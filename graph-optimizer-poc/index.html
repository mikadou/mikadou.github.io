What is implemented

Model and training

Graph state

Only variable nodes are represented. Directed edges encode greater than. Node IDs and tensor order are randomized between episodes.

Persistent memory

Every node owns a 32-dimensional hidden vector. Two directional message-passing rounds update it before each action. Hidden state persists inside an episode and resets to zero for a new instance.

Action

The policy scores every (node, value) pair, then applies the highest-scoring assignment. The same network is reused until the graph is feasible or the budget is exhausted.

Training signal

For a reliable POC, supervised teacher trajectories set the first incorrect node along the chain to 2N − 1 − depth. The test asks whether the learned recurrent procedure generalizes to unseen chains.
