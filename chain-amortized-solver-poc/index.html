Value real successor graphs by final solution quality minus future solver cost

For a selected variable, the learned proposal head generates candidate values and each candidate is actually applied to a temporary solver state. The critic predicts an absolute continuation value: final solution utility minus the solver actions still required from that successor. The benchmark now also includes an oracleStepsToGo control that uses the same candidate pool but ranks candidates by measured teacher recovery steps instead of the learned critic.

1. The solver transition is executed, not imagined

For candidate (i,v), the engine clones the current state, applies xᵢ=v, and rebuilds the graph from that successor. In a real CP/MIP adapter, this is where propagation, domain changes, soft-constraint updates, and objective recomputation occur. The critic therefore evaluates consequences that the solver actually produced.

2. V(s) predicts absolute final utility minus future compute

For this feasibility PoC, a continuation that reaches a valid chain gets final utility 1. Every subsequent solver action costs 0.02. The critic target is therefore 1 − 0.02 × future steps when the teacher solves, or only the accumulated negative action cost when the practical rollout guard is exhausted unsolved.

We no longer sum future objective improvements. A terrible state cannot look valuable merely because it has more room to improve.

3. Oracle steps-to-go tests the candidate/action abstraction directly

For every proposed value, oracleStepsToGo temporarily applies the candidate and then runs the handcrafted teacher from that successor several times. It chooses the value with the lowest mean remaining number of teacher moves. No learned critic participates in this choice.

If ORACLE_STEPS succeeds at n=20 while the GNN does not, the proposal pool and one-variable action abstraction are sufficient and the remaining problem is learning the successor ranking. If the oracle also fails, training the critic longer cannot solve the underlying candidate/action limitation.

4. The objective remains state information

The global solver node carries assignment progress, observed violation rate, violation magnitude, and the adapter-reported objective/quality. These features help the critic estimate how expensive recovery will be, but they are not repeatedly paid out as future reward. There is no required remaining-budget feature in this version.

5. Proposal learning remains separate

The Gaussian (μ,σ) head is still only a proposal mechanism trained from demonstrations, with DAgger-style learner-state coverage. It is not the final decision rule. Candidate values are temporarily executed and the resulting states are compared by the shared critic or, for the oracle control, by measured recovery steps.

What this experiment tests

The diagnostic log reports criticTargetSpread, successorRankHit, and now ORACLE_STEPS. Together they separate three questions: do successor candidates actually differ in future cost, can the learned critic rank those differences, and would exact ranking of the existing candidate pool be enough to solve the chain?
