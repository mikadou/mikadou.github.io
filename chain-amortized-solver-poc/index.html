1. Behavioral cloning remains the initialization

The GNN learns the violated-endpoint repair candidates and the numeric MLP learns the teacher's replacement-value distribution. The two supervised heads are trained exactly as in the successful imitation experiment.

2. REINFORCE fine-tunes repair decisions only

After imitation, the solver exposes the endpoints of currently violated constraints as the repair action mask. The GNN policy chooses which candidate to repair and the same value MLP samples the replacement value. No successor critic or rollout value model is introduced.

3. Reward directly measures solver progress

Each repair receives violation-energy decrease minus a small per-move cost, with a terminal bonus for reaching feasibility. A scalar running baseline reduces REINFORCE variance. The experiment therefore asks whether solver feedback can reduce repair effort beyond the demonstrated heuristic.

What would count as success?

Behavioral cloning should first recover the teacher as before. During RL, solve rate should remain near 100% on trained sizes while average or median repair moves fall. The copyable log contains BC_BASELINE, RL, RL_FINAL, and RL_BENCH lines for a direct comparison.
