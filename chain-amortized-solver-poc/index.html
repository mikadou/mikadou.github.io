Can a neural policy simply imitate the handcrafted repair heuristic?

This version deliberately removes the critic, successor ranking, rollout oracle, and RL machinery. A message-passing GNN learns which variable node to repair. A small generic MLP learns the numeric value to assign from the selected variable's ordinary node features. Both are trained only from teacher demonstrations.

1. Variable selection stays with the proven GNN classifier

Repair training states contain one or more violated chain constraints. The GNN classifies variable nodes that touch a violated constraint, matching the handcrafted heuristic's repair candidate set.

2. Value selection is now just supervised regression

The old toy-specific linear rule has been removed. A two-layer MLP receives the selected variable's normal node-feature vector and predicts the teacher mean value. Training uses plain mean-squared error. At execution the policy samples with the teacher's fixed σ=1.

3. The two heads cannot destabilize each other

The repair GNN and numeric value MLP use separate optimizers and parameter sets. Value training does not change the repair encoder, and repair training does not change the value MLP. This keeps the toy focused on representational ability instead of multi-objective training interference.

4. No RL yet

The only question here is whether a neural policy can reproduce the reference heuristic. If this works reliably, the same policy architecture can then be fine-tuned with a small RL objective based on solver improvement and move cost.

What would count as success?

We want high variable-head F1, low value MAE, and a learned closed-loop solve rate close to the handcrafted heuristic around the trained sizes. If oracleEndpoints succeeds but the full policy does not, node selection is the issue. If oracleValue succeeds but the full policy does not, numeric value imitation is the issue.
