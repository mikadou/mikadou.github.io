Can RL discover that node ID is the solution?

For a chain of n integer variables with values restricted to 0…n−1, the only assignment satisfying x₀ < x₁ < … < xₙ₋₁ is xᵢ = i. The agent is never shown that solution. It must learn it from constraint-improvement rewards while choosing both the variable i and value v on every move.

What is actually being learned

Joint action choice

The agent does not receive a fixed variable order. On every step it chooses a complete action (i,v): which variable to change and which value to assign.

A shared neural scorer evaluates every candidate pair. The same small MLP is reused for all nodes, values, and chain lengths, so testing at n=100 does not require a 100-specific output head.

RL, not supervised learning

There are no exact-solution labels in training. Episodes start from random permutations. Reward is only the reduction in monotonic-constraint energy, plus a terminal bonus when all inequalities are satisfied.

Exploration is ε-greedy: early episodes choose many random (i,v) pairs; ε decays toward 0.04 so later episodes increasingly exploit the learned action-value scorer.

Why the solution is unique

There are exactly n variables and each value must lie in 0…n−1. A strictly increasing sequence of n integers from a set containing only n integers must therefore use every value exactly once and in order:

x₀=0, x₁=1, …, xₙ₋₁=n−1.

The environment knows only the variable domains and monotonic inequalities. The identity rule is never supplied as a training target.
