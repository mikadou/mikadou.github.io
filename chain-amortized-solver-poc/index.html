Proof of concept · typed GNN + reinforcement learning

Can a factor-graph GNN discover a feasible construction from terminal reward alone?

Every variable has integer domain 0…1000. The only constraints are x₀ < x₁ < … < xₙ₋₁. The GNN chooses joint actions (i,v) and gets a budget of up to 3n moves, so it can revise earlier choices. Nothing checks or repairs partial assignments during training: reward arrives only when a complete feasible solution is first found or when the move budget is exhausted.

Graph representation

Two node types

Variable nodes Vᵢ carry a variable-type bit, normalized node ID i/(n−1), assignment status, and assigned value when present.

Constraint nodes Gₖ represent xₖ₊₁ > xₖ and carry their own type bit and normalized constraint ID.

Typed message passing

Four directed edge types distinguish smaller-operand and greater-operand roles in both directions. Each edge type has its own learned message matrix.

Six residual message-passing rounds produce a 24-dimensional embedding. There is no raw node-ID bypass around the GNN.

Terminal-only RL with correction moves

Full joint action sequence

The first n moves must assign each variable once. The remaining budget may choose any variable again and overwrite its value, giving the learned policy a chance to recover from earlier mistakes.

As soon as a complete assignment becomes strictly increasing, the episode terminates immediately with reward +1. If no feasible assignment is found by 3n moves, the episode ends with reward −1. There is still no intermediate feasibility signal.

REINFORCE + curriculum

Policy-gradient learning assigns the terminal return back to every action in the episode, with a running baseline to reduce variance and a small entropy bonus to preserve exploration.

The curriculum begins at the selected start length. It promotes from n to n+1 only after a 30-episode window exceeds 70% success and the greedy policy also solves the current length. Exploration temperature is reset upward after each promotion.

No feasibility oracle during learning

The environment does not label individual moves as good or bad, does not propagate partial domains, and does not expose a target formula such as v=k·i. The only learning signal is whether the evolving full assignment eventually satisfies all greater-than constraints before the 3n-move cap.

Everything runs locally in your browser. No training data or model state is uploaded.
