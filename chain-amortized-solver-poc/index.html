What this PoC does — and does not — prove

Hypothesis under test

A generic metaheuristic repeatedly pays to discover correlations between variables. A policy trained on a recurring instance distribution can internalize those correlations and spend almost no search effort at deployment.

The policy is deliberately simple: a 1-D convolutional network maps the whole target sequence to value logits. A feasibility-aware decoder masks values that would violate the strict chain.

Important caveat

This first experiment uses imitation learning from an exact dynamic-programming oracle. It tests whether the solver can represent and generalize a reusable optimization heuristic. A later PoC should remove the oracle during training and learn from objective feedback/self-improvement.

SA is intentionally generic but not crippled: it proposes only feasible single-variable changes and uses a temperature schedule. A block-move SA would be a useful next baseline.
