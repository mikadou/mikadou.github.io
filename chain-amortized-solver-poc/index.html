What changed

Much smaller representation

Node embeddings are now 8-dimensional instead of 24-dimensional. The normalized semantic node position i/(n−1) is still an input feature, so the model has direct access to the simple positional signal.

The selected message depth can be 0, 1, 2, or 6. At depth 0, the variable actor sees only the encoded node features: there is no graph mixing at all.

Stabilized message updates

When message passing is enabled, each residual message update is normalized across the embedding dimensions before the ReLU. This is intentionally simple row-wise LayerNorm-style normalization rather than another learned module.

The goal is to preserve the positional signal instead of repeatedly amplifying or distorting it through six unnormalized recurrent graph updates.

Cleaner PPO experiment

Larger rollout batches

PPO now collects 32 episodes per update instead of 4. That should reduce the variance of the terminal-reward policy gradient substantially, especially at the tiny curriculum sizes where the old implementation updated from only a handful of transitions.

No self-imitation

The successful-trajectory replay auxiliary loss is disabled. Training is now just the small actor-critic GNN, PPO/GAE, entropy regularization, and the terminal reward. This removes one more mechanism that could obscure what is actually helping.

Environment and reward are unchanged

Same joint decisions

The actor still chooses both the variable i and value v. Variable choice is categorical; the selected variable embedding parameterizes a Gaussian latent that maps through a sigmoid to integer v∈0…1000.

The first n moves assign every variable once; the remaining training budget can overwrite variables, with immediate termination on a feasible full chain.

Same terminal shaping

There is no propagation and no per-step feasibility oracle. At episode termination, a failed assignment receives the fraction of adjacent xᵢ < xᵢ₊₁ constraints satisfied.

A complete solution receives an additional +2 plus an efficiency bonus up to +1, so solving in exactly n moves still gives the maximum reward 4.

How to read the ablation

Start with 0 rounds. If that learns quickly, the sequential PPO/action formulation is viable and graph mixing was the main problem. Then try 1 and 2 rounds. If performance degrades monotonically with depth, we have direct evidence that the old six-round GNN was destroying an already-sufficient positional representation rather than adding useful structure.
