Can the GNN learn a value rule from neighboring variables?

The handcrafted solver no longer uses a variable index to choose values. Each chain starts at a randomized absolute value, then every variable that must be greater looks through the constraint graph to the neighboring variable that must be smaller and proposes neighbor value + 2. Node index, normalized position, graph-size coordinates, and the sampled root offset are not exposed as learner features.

Headline benchmark: —

1. The teacher is local, relational, and translation-invariant

Each chain samples a root value uniformly while reserving enough headroom for the longest benchmark chain. Construction then proceeds left-to-right. Every later value is sampled around smallerNeighbor + 2. During repair, the teacher selects the greater-side node of a violated constraint and applies exactly the same local rule.

2. No node ID, position, or offset feature

Variable nodes expose only type, assigned state, and current value. Constraint nodes expose type and satisfied / violated / unresolved status. There is no absolute index, relative index, normalized position, graph-size coordinate, or explicit root-offset feature. Ordering information exists only in the typed constraint edges: smaller side versus greater side.

3. The value learner must use message passing

The value head reads a GNN embedding, not the selected node's raw features. In the bipartite graph the relevant variable is two hops away, so two message-passing rounds are the natural minimum. A separate GNN encoder is used for value prediction so learning the relational value rule cannot destabilize the already-easy repair-node classifier.

4. Small training graphs cover the numeric domain

The root offset is randomized over the largest safe range for each chain length, leaving a fixed safety margin below 1000. Values are now normalized by the full 0–1000 domain before entering the GNN and for the regression target, so the learned numeric signal stays in roughly [0,1]. This lets short training chains cover the relevant numeric range while graph size itself remains held out.

What would count as success?

If the network really learns neighbor + 2, training on chains up to n=20 should now transfer much further in graph size because both train and test exercise the same local relation across a broad numeric range. The diagnostic log reports construction-value MAE, repair-value MAE, variable F1, solve rate, and probes showing the actual smaller-neighbor value, predicted mean, and teacher target.

RL is disabled for this experiment

First we re-establish pure imitation under the relational teacher with randomized absolute offsets and stable domain normalization. Once that works, RL can be added again without a positional or numeric-range shortcut.
