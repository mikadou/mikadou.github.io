Proof of concept · typed GNN + PPO actor-critic

Can a factor-graph GNN learn a feasible construction from terminal reward alone?

Every variable has integer domain 0…1000. The only constraints are x₀ < x₁ < … < xₙ₋₁. The actor chooses both the variable and value, gets up to 3n moves with overwrites, and receives no intermediate feasibility feedback. A complete feasible chain ends the episode immediately with +1; exhausting the budget gives −1.

Graph representation

Two node types

Variable nodes Vᵢ carry a variable-type bit, normalized node ID i/(n−1), assignment status, and assigned value when present.

Constraint nodes Gₖ represent xₖ₊₁ > xₖ and carry their own type bit and normalized constraint ID.

Typed message passing

Four directed edge types distinguish smaller-operand and greater-operand roles in both directions. Each edge type has its own learned message matrix.

Six residual message-passing rounds produce 24-dimensional node embeddings. There is no raw node-ID bypass around the GNN.

Factorized PPO actor-critic

Still chooses both i and v

The actor first samples which variable to modify from a categorical distribution over variable-node embeddings. The chosen variable embedding then produces a Gaussian (μ, σ) over a continuous latent value; a sigmoid maps that latent into integer v∈0…1000.

This replaces one giant n×1001 categorical action with π(i|s)π(v|s,i), while leaving the policy responsible for both decisions.

PPO + learned critic

A critic pools the GNN embeddings and predicts V(s). Batches of episodes use generalized advantage estimation (GAE), clipped PPO policy updates, a value loss, and a small entropy bonus.

Successful trajectories are also kept in a small self-imitation buffer. Those are generated only by the agent itself from terminal successes; there are still no solver labels or target assignments.

Curriculum and reward

Terminal reward only

The first n moves ensure every variable has an initial value. Later moves may overwrite any variable. The episode terminates immediately when the full assignment becomes strictly increasing, or at the 3n cap.

There is no propagation or intermediate feasibility oracle. Rewards are zero until the terminal transition, which is +1 for success or −1 for failure.

Greedy-driven promotion

Training concentrates on the current curriculum size but mixes in previous sizes to reduce forgetting. Every few PPO updates, the deterministic greedy actor is evaluated separately.

The curriculum promotes to n+1 after enough current-size experience and at least 80% greedy solve rate. Exploratory stochastic success is displayed for diagnosis but no longer blocks promotion.

Browser backend

On Android, TensorFlow.js uses the CPU backend for reliability. This avoids both WebGL shader-link failures and missing WASM kernels such as UnsortedSegmentSum. Other platforms still prefer WASM with CPU fallback.

Everything runs locally in your browser. No training data or model state is uploaded.
