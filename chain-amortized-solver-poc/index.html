What is actually being learned

Joint action choice

The agent never receives a fixed variable order. A shared MLP scores every pair (i,v): which variable to choose and which value to assign. Its only numeric inputs are normalized node ID and normalized candidate value.

At deployment the policy repeatedly chooses the highest-scoring remaining node/value pair, so a learned identity relation produces a full solution in exactly n joint choices.

RL, not supervised learning

There are no exact-solution labels. Each exploratory action fixes one variable, then a tiny generic bound propagator enforces the strict monotonic constraints and domains. The agent receives +1 if the partial assignment is still feasible and −1 if propagation proves a contradiction.

This is a contextual-bandit RL problem: immediate feedback is enough, so there is no noisy multi-step credit assignment. ε-greedy exploration collects experience, and balanced replay prevents the rarer positive actions from being drowned out by negative ones.

Why the solution is unique

There are exactly n variables and each value must lie in 0…n−1. A strictly increasing sequence of n integers from a set containing only n integers must therefore use every value exactly once and in order:

x₀=0, x₁=1, …, xₙ₋₁=n−1.

The environment contains only domains plus monotonic constraints. The identity rule is never inserted as a training label; it is the relation that survives propagation.
