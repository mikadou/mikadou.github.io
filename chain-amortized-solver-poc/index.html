Proof of concept · behavior cloning

Can the typed GNN represent the handcrafted local-repair algorithm?

This experiment removes RL credit assignment completely. A handcrafted teacher generates trajectories. Constraint nodes explicitly expose whether their current xᵢ < xᵢ₊₁ relation is violated, satisfied, or unresolved. The GNN is trained by imitation to reproduce the teacher's variable-selection distribution and its N(2i,1) value distribution. At inference, the GNN is not given the teacher's repair mask: it must recover the local-repair behavior from graph state and message passing.

Constraint state is now part of the graph

Eight node features

Nodes carry [variable type, constraint type, absolute position, relative position, problem size, assigned, value, constraint status]. Variable nodes use the assignment/value fields; constraint nodes use the final status field.

For a constraint node representing xᵢ < xᵢ₊₁, status is +1 when violated, -1 when satisfied, and 0 while either endpoint is still unassigned.

One round is sufficient in principle

A violated constraint node is directly connected to its two endpoint variables. With one typed message-passing round, those variables can receive the violation signal and the variable head can learn to assign probability only to endpoints of violated constraints.

The 0-round setting is intentionally retained as a control: it cannot receive dynamic constraint status from neighboring constraint nodes.

What exactly is imitated?

Variable-selection distribution

During construction, the teacher is uniform over all unassigned variables. During repair, it is uniform over all variables directly adjacent to at least one violated constraint.

The loss uses that complete soft target distribution rather than the one random endpoint sampled in a particular trajectory. Choosing any valid teacher endpoint is therefore treated as correct.

Value distribution

Conditioned on choosing variable i, the teacher samples from N(2i,1), rounded and clipped to 0…1000. The GNN's existing mean and log-standard-deviation heads are trained to reproduce mean 2i and σ=1 directly in value space.

This removes the old PPO latent-Gaussian mismatch: the supervised target is now exactly the distribution used by the handcrafted algorithm.

Teacher data and inference

Online teacher trajectories

Training lengths are sampled uniformly from the selected range. Each teacher episode runs the same robust 3n local-repair heuristic. A small balanced subset of construction and repair states is used for each supervised update so training remains practical in the browser.

No repair mask at inference

The teacher's candidate set exists only in the imitation loss. When the trained GNN is benchmarked, its variable head samples over all variable nodes. It must use assigned-state features and messages from satisfied/violated constraint nodes to recover the teacher policy.

This makes the comparison a genuine representational test rather than hard-coding the teacher's endpoint selection into the learned solver.

Why this experiment matters

If the blue imitation curve approaches the green teacher curve, then the typed GNN architecture can represent the robust local algorithm and our previous failures were primarily learning/credit-assignment failures. If behavior cloning still fails badly, the remaining problem is architectural or representational, which is a much narrower diagnosis.
