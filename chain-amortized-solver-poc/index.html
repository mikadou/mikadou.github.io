Can PPO learn a size-independent integer-spacing rule?

The environment is unchanged: integer variables in 0…1000, only x₀ < x₁ < … < xₙ₋₁, the policy chooses both i and v, training gets at most 3n moves, and reward is computed only at episode termination. The key fix is that node features now expose absolute position and problem size as well as relative position, and training samples uniformly across the full selected size range instead of progressing through one tiny curriculum size at a time.

Scale-aware node features

Seven features per node

Variable nodes now carry [type-var, type-constraint, absolute position, relative position, problem size, assigned, value]. With MAX_TEST_N=100, the key static features are i/99, i/(n−1), and n/100.

This means a size-independent construction such as v ≈ k·i + b is representable directly. Previously, an unassigned node at zero message rounds effectively knew only i/(n−1), which encouraged a fixed output curve whose integer gaps collapse as n grows.

Constraint nodes use the same scale

Constraint nodes receive analogous absolute and relative positions plus the same problem-size feature. Assignment status and assigned value remain zero for constraint nodes.

The 8-dimensional encoder remains shared across graph sizes. No raw node-ID bypass is added to the action head; all features still pass through the learned node encoder first.

Mixed-size PPO training

Uniform across the selected range

Each episode now samples n uniformly between the configured training minimum and maximum. A run configured as 2…20 therefore trains on all of those lengths throughout the run instead of concentrating on one current curriculum size.

This removes the shortcut where PPO only needs enough output slope for tiny chains before moving on.

Cleaner optimization setup

PPO still collects 32 episodes per update, uses the 8-dimensional encoder, GAE, clipped PPO, a learned critic, and entropy regularization. Self-imitation remains disabled.

0 message rounds is now the default. That isolates the scale fix first. Once the zero-round model works, 1/2/6 rounds can be compared again without changing the environment or reward.

Environment and reward are unchanged

Same joint decisions

The actor still chooses both variable i and value v. Variable choice is categorical; the selected variable embedding parameterizes a Gaussian latent mapped through a sigmoid to integer v∈0…1000.

The first n moves assign every variable once; the remaining training budget may overwrite variables, with immediate termination on a feasible full chain.

Same terminal shaping

There is no propagation and no per-step feasibility oracle. At termination, a failed assignment receives the fraction of adjacent xᵢ < xᵢ₊₁ constraints satisfied.

A complete solution receives an additional +2 plus an efficiency bonus up to +1, so solving in exactly n moves still gives the maximum reward 4.

What this test should tell us

If 0 rounds now generalizes substantially better beyond the training maximum, the previous failure was largely a representation/scale mismatch. If it still fails despite explicit i-scale and n features plus mixed-size training, then the remaining bottleneck is much more likely the sequential PPO action formulation or Gaussian value parameterization rather than the GNN.
