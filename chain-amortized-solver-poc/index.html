What was wrong in the previous imitation test?

Illegal construction choices were not masked

The old imitation policy sampled from all variables even while some variables were still unassigned. Small classification errors could therefore waste the tight 3n budget overwriting already-assigned variables before construction was complete.

The corrected engine applies the environment's legal action mask: before completion, only unassigned variables are eligible. Once the assignment is complete, all variables become eligible and the network must learn to concentrate probability on violated-constraint endpoints.

The value loss was nearly scale-free

The old loss regressed 2i/1000 with ordinary MSE. A 10–20 integer-unit error therefore cost almost nothing relative to the variable-selection loss, so the network could minimize training loss while predicting nearly the same small value everywhere.

The corrected loss works in integer value units with a robust Huber objective. The mean rule 2i is supervised on every variable in every labeled state, not only on whichever variables happened to be teacher candidates.

Constraint-state graph

Eight node features

Nodes use [variable type, constraint type, absolute position, relative position, problem size, assigned, value, constraint status]. For constraint nodes, status is +1 when violated, -1 when satisfied, and 0 while unresolved.

One message round should suffice

A violated constraint node is directly connected to its two endpoint variables. One typed message round can therefore carry the violation signal to exactly the variables the handcrafted heuristic considers for repair.

0 rounds remains a useful negative control because the variable head then cannot see constraint status.

DAgger-style imitation

Teacher warm-up

Early updates use handcrafted teacher trajectories. Each labeled state carries the complete soft target: uniform over all legal construction choices, or uniform over all endpoints touching at least one violated constraint during repair.

Learner-state relabeling

After warm-up, most batches include trajectories generated by the GNN itself. The handcrafted heuristic labels those visited states. This is DAgger-style dataset aggregation and directly addresses behavior-cloning covariate shift.

Two diagnostics separate representation from closed-loop compounding

Repair candidate mass measures how much probability the variable head puts on teacher-valid endpoints. Value mean MAE measures how closely the value head reproduces 2i in integer units. If those become strong while solve rate remains weak, the remaining problem is closed-loop stochastic compounding rather than basic representational capacity.
