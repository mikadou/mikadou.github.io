Growing Neural Cellular Automata

Train a tiny neural cellular automaton in the browser, then replay one single growth rollout step by step on a separate canvas.

Model weights are saved in IndexedDB. Training-pool states and rollout state live in RAM.

Phone mode starts small. Use Load saved model before running a trained model after refresh.

Run notes

Use this section after training or after tapping Load saved model. It does not use the training pool; it runs one fresh seed forward with the current model.

The rollout is stochastic because the NCA uses a random cell-update mask. Tapping New seed starts a new rollout from one center cell.

If the run looks empty, tap Load saved model first, then New seed.
