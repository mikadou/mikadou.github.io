Growing Neural Cellular Automata

Train a tiny neural cellular automaton directly in this browser tab. This version has a phone-safe training path for Android/Pixel devices.

Model weights are saved in IndexedDB. Metadata is saved in localStorage. Nothing is uploaded.

Phone mode defaults to 24×24, batch 1, and very short rollouts so the UI stays responsive.
